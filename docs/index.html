SWIFT-TEC v4

TEC Archive + Forecast + GNSS DOP
• TEC input: BoM or NOAA(GloTEC) (select a source)
• Base extraction + additive model: ΔStorm = kStorm * BaseTEC * (rStorm - 1)
• SStorm (rStorm): Mukhtarov-based (season, latitude and Kp dependent) + superstorm tail implementation
• NOAA input: one day before the analysis date (UTC) fetched via API (12 frames at 2-hour intervals) → 2° × 5° grid
• The 4-day forecast repeats 12 NOAA frames by UTC time of day (time-varying pattern)
• Update: Linear interpolation from 2 hours to 30 minutes; BaseKp/Flare also use daily repetition + linear interpolation
• Update: Kp supports automatic fetching and manual input

8b. GNSS / DOP Settings

multi-GNSS / satellite select
• Load GPS / Galileo / GLONASS / BeiDou / QZSS TLEs and calculate DOP using selected satellites.

• DOP modes display GDOP / PDOP / HDOP / VDOP / TDOP and DOP × TEC errors.
• NOAA 30-minute TEC values are rendered as grid cells without zero filling, Fourier smoothing or automatic rescaling.
